# Ночной отчёт — 2026-11-21

## Почему задача (B), а не (A)
Проверил очередь городов (Katowice, Szczecin, Lublin, Bydgoszcz, Białystok, Rzeszów) по правилу «нет файла в репо И нет ветки night/* с ним» (`git branch -r`):

- **Katowice** — файл уже в `main` (смёржен, есть в sitemap.xml).
- **Szczecin, Lublin, Bydgoszcz, Białystok, Rzeszów** — у каждого уже есть минимум одна ветка `night/*` с готовым черновиком (например `night/2026-10-01:cukr-lublin.html`, `night/2026-10-02:cukr-bydgoszcz.html`, `night/2026-10-04:cukr-bialystok.html`, `night/2026-10-06:cukr-rzeszow.html`, и много веток с `cukr-szczecin.html` вплоть до вчерашней `night/2026-11-20`).

По буквальному правилу задачи все 6 городов уже «заняты» черновиками, ожидающими проверки и смёржа владельцем. Создавать ещё один дублирующий черновик для уже задрафтенного города не стал — пошёл в задачу (B).

**Замечание (не блокер):** судя по истории веток, в ночи после 2026-10-06 агенты повторно создавали черновики именно Katowice и Szczecin (а не Lublin/Bydgoszcz/Białystok/Rzeszów), хотя у всех пяти уже были ветки. Похоже, проверка `git branch -r` в какой-то момент не применялась или применялась только к файлам в `main`. Возможно, стоит решить вручную: смёржить/отклонить старые черновики Lublin/Bydgoszcz/Białystok/Rzeszów, чтобы очередь не «застревала» на Szczecin.

### Новые пункты и факты, проверенные напрямую (WebFetch)

1. **Подача CUKR при открытом деле на pobyt czasowy i pracę автоматически закрывает это дело «по силе закона» (umorzenie), без отдельного решения; если CUKR отклонят — открытого дела уже не останется.**
   Источник: https://www.gov.pl/web/udsc/cukr-QA — Pytanie 13 (точная цитата получена через WebFetch: «Twoje postępowanie o udzielenie zezwolenia na pobyt czasowy i pracę zostanie umorzone z mocy prawa» / «Nie dostaniesz decyzji o umorzeniu postępowania»).

2. **Карта CUKR не даёт права зарегистрироваться безработным/ищущим работу в urzędzie pracy (в отличие от статуса UKR).**
   Источник: https://zielonalinia.gov.pl/cudzoziemiec-z-karta-pobytu-cukr-a-rejestracja-w-urzedzie-pracy/ (официальный сайт Zielona Linia, инфолиния Минтруда Польши; статья от 31.08.2026, правовая основа — закон от 20.03.2025 о рынке труда, art. 1 ust. 3).

3. **Изменение адреса нужно сообщить воеводе в течение 15 рабочих дней, иначе письма считаются доставленными по старому адресу.**
   Источник: https://www.gov.pl/web/udsc/cukr-QA (Q50–51, подтверждено через WebFetch-сводку этой страницы).

4. **MOS может без объяснения блокировать подачу заявления при неполных/несовпадающих данных в реестрах — нужно идти в urząd gminy с паспортом.**
   Источник: https://www.gov.pl/web/udsc/cukr-QA (Q30–34, Q61).

5. **Дубликат карты стоит 200 зл (потеря не по вине владельца) или 300 зл (повторная потеря по вине владельца).**
   Источник: https://www.gov.pl/web/udsc/cukr-QA (Q59).

Все пять фактов — из официальных источников (`gov.pl`, `zielonalinia.gov.pl`), открытых и прочитанных напрямую через WebFetch, а не из поискового сниппета. Проверил, что эти темы ранее не упоминались на сайте (`grep` по всем `*.html` — ничего не нашёл по «umorzenie», «urząd pracy», «15 робочих днів», «дублікат картки», «заблокувала подачу»).
